# Match analysis artwork

`wind-swordsman.png` is an original decorative fantasy illustration generated with the built-in `image_gen` tool on 2026-09-20. It is not a player portrait or an official champion splash. Champion avatars remain the existing game assets.

Used by `stats-arena.css` with dark gradient overlays to keep player names and controls legible. The artwork is bundled locally and needs no remote fetch.

## Generation prompt

Use case: stylized-concept. Asset type: production background artwork for a premium League of Legends match analytics desktop UI, NOT a screenshot or mockup. Create a wide cinematic 3:1 landscape matte illustration. Dark graphite mineral stone, subtle etched brushed-metal edges and drifting mist; an elegant anonymous fantasy wind swordsman with long tied black hair and weathered armor occupies only the right third, facing left, cropped bust, subdued desaturated rendering. Left two thirds intentionally nearly empty charcoal negative space for readable interface text. Palette graphite gray, restrained smoky steel blue highlights and tiny aged champagne gold accents; absolutely no bright neon, no saturated purple. Painterly AAA fantasy game splash art quality, low key lighting, delicate environmental texture, premium refined composition. Keep all edges fading to deep charcoal so the asset blends seamlessly beneath dark UI gradients. No text, no logos, no interface panels, no letters, no borders, no charts, no watermark.
